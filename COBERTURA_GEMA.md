# Cobertura de la gema (RPG Manager)

Este proyecto cubre todos los retos indicados por la gema:

- Reto 0 - Personaje base con encapsulamiento: `personaje.py`, `Personaje.java`
- Reto 1 - Herencia basica: `guerrero.py`, `mago.py`, `arquero.py` y equivalentes Java
- Reto 2 - Constructores y `super()`: incluido en las clases anteriores
- Reto 3 - Sobrescritura: `atacar()` y `recibir_dano()` redefinidos por clase
- Reto 4 - Sobrecarga: `mago.py` y `Mago.java`
- Reto 5 - Clase abstracta: `Personaje` con `habilidad_especial()`
- Reto 6 - Contrato Combatiente: `combatiente.py`, `Combatiente.java`, `monstruo.py`, `Monstruo.java`
- Reto 7 - Composicion, agregacion y asociacion: `item.py`, `inventario.py`, `mision.py` y equivalentes Java
- Reto 8 - Arena de combate y entrega final: `arena_combate.py`, `ArenaCombate.java`, salidas y reflexion

Archivos de entrega final:
- `herencia/python/salida_python.txt`
- `herencia/java/salida_java.txt`
- `herencia/reflexion.md`
